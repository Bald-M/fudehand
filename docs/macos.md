# macOS 使用说明

界面图鉴运行 SwiftUI/AppKit 原生外壳。案例继续保留各自的 Vue、React 或 HTML 工具链，在系统 WKWebView 中展示。

## 启动与构建

需要 macOS 14+、Swift 6+、Node.js 22.12+、pnpm 11.7.0。安装 Xcode Command Line Tools 即可，不需要完整 Xcode，也没有第三方 Swift 包依赖。

```bash
pnpm install
pnpm dev                 # Debug 构建并打开 App
pnpm build:native        # Release 构建并进行本地 ad-hoc 签名
open dist/界面图鉴.app
```

App 启动后会读取仓库 `catalog.json`，只启动当前作品的案例服务；切换到其他已启用作品时再按需启动它，已启动的服务保留到 App 退出。关闭最后一个窗口或使用 ⌘Q 退出，会停止本次启动的案例。App 异常退出后，案例启动器也会通过所有权管道关闭来清理进程。

某个作品启动失败（如端口占用）时，App 只在该作品上显示具体错误并提供重试，其他作品不受影响。它不会终止占用端口的其他进程。

构建脚本把本机源码目录、Node 路径和启动时 PATH 写进 App 的 `Contents/Resources/workspace.json`。这是本地开发工具，需要保留源码、node_modules、Node 和 pnpm；复制 App 到另一台机器不能直接运行案例。移动目录后使用 App 的“打开项目目录…”选择仓库；更换 Node 版本或删除旧 Node 后重新构建 App。

SwiftPM 构建和模块缓存默认写到系统临时目录。`UI_ATLAS_SWIFT_SCRATCH` 可覆盖构建目录，`UI_ATLAS_SWIFT_MODULE_CACHE` 可覆盖模块缓存目录。不要同时在同一 scratch 目录运行两个 Swift 构建。

## 画布操作

交互方式参照 Figma 设计模式：点选画框后即可直接操作网页，无需额外开关。

**选择与移动**

- 点击未选画框（标题或内容）只选中，显示蓝色选框，这次点击不传给网页；悬停时显示细描边。
- 点击已选且唯一选中的画框内容，输入直接交给网页，这个画框称为活动画框。Return 也可把键盘焦点交给唯一选中且已加载的画框。
- 拖动任意画框位置移动（3pt 阈值后开始）；属于多选时整组一起移动。拖动空白画布框选，与画框相交即选中，Shift 追加；Shift + 点击画框加入或移出选择。
- 多选（≥2 个）时画框内容不接收网页输入；点击其中一个画框（无 Shift）收缩为单选，该次点击仍不传给网页。
- 点击空白或按 Esc 取消选择。活动画框中的 Esc 先交给网页，网页未处理且没有打开的弹窗时才取消选择。
- 加载中或失败的画框可以选择和移动，但不接收网页输入；“重新加载”与“在浏览器打开”按钮始终可点击。
- 方向键移动选择 10，Shift + 方向键移动 100，每次按键为一步撤销；一次拖动也是一步撤销。⌘A 全选画框（画布持有焦点时）。
- 拖动时画框边缘与中线靠近其它画框 6 屏幕点内会吸附并显示红色参考线；按住 ⌃ 拖动可关闭吸附。方向键移动不吸附。

**导航**

- 空格 + 拖动、鼠标中键拖动，或抓手工具拖动，平移画布。工具栏分段控件切换“移动 V”与“抓手 H”，也可用 V / H 键。
- 滚轮或触控板滚动：起点在活动画框内容内则滚动网页，否则平移画布。每个手势（含惯性）锁定起点处的目标。
- ⌘ / ⌃ + 滚轮或触控板捏合，以指针为锚点缩放，在任何位置（包括活动画框上方）都控制画布。缩放范围 5%–400%。
- 工具栏提供缩小、缩放百分比（点击回到 100%）、放大与适应全部。菜单快捷键：⌘+ 放大、⌘− 缩小、⌘1 100%、⌘0 适应全部、⌘R 重新加载。
- 画布持有焦点时：Shift+1 适应全部，Shift+2 缩放至选择（无选择时等同适应全部），Shift+0 以画布中心为锚点回到 100%。适应全部、缩放至选择与聚焦最多放大到 100%。
- 双击画框标题，缩放聚焦到对应画框。这些过渡以及工具栏缩放、快捷键使用 200ms 动画，新的输入会立即打断并从当前状态继续。

**键盘与撤销**

- 网页持有焦点时，字母、数字与方向键交给网页；Shift+数字、V / H 和 ⌘A 仅在画布持有焦点时生效。⌘ 菜单命令始终可用。
- 画布持有焦点时 ⌘Z / ⇧⌘Z 撤销、重做画框移动；网页持有焦点时交给网页处理。切换作品、恢复默认布局、重新读取目录会清除撤销记录。

**其他**

- 在侧栏搜索或切换作品；底部显示介绍、作者与原作出处。
- 侧栏每个作品显示缩略图（作品第一个画框加载后截取，缓存在 `~/Library/Caches/界面图鉴/thumbnails/`；未生成时显示占位图）和作品目录的最近修改时间；可在“目录顺序”和“最近修改”之间切换排序，右键作品可置顶，置顶作品始终排在最前。
- 重新加载当前作品用 ⌘R 或工具栏；画框标题栏按钮可用默认浏览器打开对应页面。
- 右上角菜单选择跟随系统、浅色或深色，或恢复默认布局。

画框尺寸仍然是 **CSS 视口**，不模拟 iOS 系统或设备原生能力。App 对画框整体做视觉缩放；网页仍按配置的原始宽高进行响应式排版。外部链接在浏览器中打开，画框主页面保持在该作品的本机服务内。

## 配置与保存

`catalog.json` 继续作为作品、案例命令和默认布局的唯一来源，案例接入方式见 README。修改目录后使用“重新读取目录并启动服务”。配置无效时给出错误，正在运行的有效项目保持可用。

原生 App 通过 UserDefaults 单独保存主题、最近目录、最近作品，以及按仓库目录和作品 ID 区分的位置、缩放与视角。已移除的浏览器版 localStorage 偏好不会迁移。配置的 `layoutVersion` 变化或保存数据损坏时回退到默认布局；新增画框使用配置位置；“恢复默认布局”只重置当前作品。

## 验证

```bash
pnpm test:native
pnpm check
pnpm build:native
codesign --verify --deep --strict dist/界面图鉴.app
```

Swift 测试覆盖目录校验、URL 解析、鼠标锚点缩放、拖动坐标、适应全部与布局恢复。Node 集成测试使用真实本机 HTTP 服务验证按需启动与停止、管道关闭清理、SIGTERM、单个作品失败隔离与重试、异常退出以及保留外部占端口程序。

## 性能排查

设置 `UI_ATLAS_FRAME_LOG=1` 启动 App，会每秒向 stderr 输出一行 `[frame] hitches=N frames=M`，用于对比平移和缩放时的掉帧次数。
