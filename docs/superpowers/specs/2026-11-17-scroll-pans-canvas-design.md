# 滚动始终平移画布（#15）设计

## 意图

参照 Figma：在画布任何位置滚动都只平移画布，活动画框不再“吃掉”滚动。

## 规则

- 不按 ⌥ 的滚轮或触控板滚动（含惯性）始终平移画布，包括活动画框上方。
- ⌥ + 滚动、起点在活动画框内容内时滚动网页，用于查看比画框更长的页面。触控板手势在开始时锁定目标并保持到惯性结束，中途按下或松开 ⌥ 不切换；鼠标滚轮（无阶段）逐个事件判断。
- ⌘ / ⌃ + 滚动与捏合仍以指针为锚点缩放画布，优先于 ⌥。
- 画框滚动条已在 #28 隐藏，不变。

## 方案

- **⌥ + 滚动（选定）**：改动最小，不改变 CSS 视口。代价是需要记住快捷键，网页内的可滚动区域也要按 ⌥。
- 画框高度随内容展开：会改变 CSS 视口高度，与 Issue 非目标冲突。
- 手动调整画框尺寸：需要新交互与持久化，同样改变视口。

## 改动范围

- `AtlasCore/ScrollRouting.swift`：`route` 增加 `pageModifier` 输入，只有 `overActivePage && pageModifier` 时才是 `.page`。
- `AtlasApp/CanvasView.swift`：把 `.option` 传入。
- `AtlasApp/WorkspaceView.swift`：底栏提示加入“⌥滚动网页”，便于发现。
- `docs/macos.md` 滚动规则同步；浅色、深色截图放 `docs/evidence/`。
