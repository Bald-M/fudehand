# Find (⌘F) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ⌘F opens a find bar that steps through layers whose text content or name matches a query; `design_find_nodes` gives Agents the same matches.

**Architecture:** Matching rules live in `FudehandCore/DesignFind.swift`. `FudehandStore.findLayers(_:)` wraps them and is called by both the find bar and the `find_nodes` control command. The find bar's state is a small `FindModel` (ObservableObject owned by the store, like `LayerSelection`) so typing redraws only the bar; stepping reuses `setSelection` and `focus`.

**Tech Stack:** Swift 6 / SwiftUI + AppKit (Swift 5 mode), swift-testing; Node 22 + Vitest.

**Spec:** `docs/superpowers/specs/2026-11-24-find-design.md` (issue #257)

## Global Constraints

- UI copy only through `L("English text")`, with the key added to all four `native/Sources/FudehandCore/Resources/*.lproj/Localizable.strings` (en, en-GB, zh-Hans, zh-Hant), using GLOSSARY terms.
- New UI source files are added to the file list in `LocalizationTests.uiSourcesHaveNoHardCodedChineseCopy`.
- Icon-only buttons: localized `.accessibilityLabel` and `.iconHitTarget()`.
- Control-channel errors are English and not localized.
- Find never edits the document: no undo step, `isDirty` unchanged.
- Docs, comments, and test names in English.

## Review Focus

- Query with leading/trailing whitespace or only whitespace → trimmed; whitespace-only finds nothing (Task 1 test).
- Accented or differently cased query ("cafe" vs "Café") → matches (Task 1 test).
- Document changes while the bar is open (the matched layer is deleted, undo brings it back) → matches are recomputed and the position is clamped, never pointing at a missing layer (Task 3 test).
- Stepping past the last / before the first match → wraps (Task 3 test).
- A text layer whose name equals its content (the default for new text layers) → listed once, with `field: "text"` (Task 1 test).

### Task 1: Matching rules in Core

**Files:**
- Create: `native/Sources/FudehandCore/DesignFind.swift`
- Test: `native/Tests/FudehandCoreTests/DesignFindTests.swift`

**Interfaces:**
- Produces:
  ```swift
  public enum DesignFind {
      public enum Field: String, Sendable { case text, name }
      public struct Match: Equatable, Sendable { public var id: String; public var name: String; public var type: NodeType; public var field: Field; public var excerpt: String }
      public static func matches(in document: DesignDocument, query: String) -> [Match]
  }
  ```

- [ ] **Step 1: Write failing tests** (`DesignFindTests.swift`, swift-testing):
  - `findsTextContentAndNamesInDocumentOrder`: frame "Home" containing text "t1" (content "Sign in") and rectangle named "sign-in background"; query `"sign"` → ids `["t1", "bg"]` in depth-first order, fields `[.text, .name]`.
  - `matchesCaseAndDiacriticInsensitively`: text content "Café Menu", query `"cafe"` → one match.
  - `listsEachLayerOnceAndPrefersText`: text layer name "Buy now", content "Buy now" → one match, `field == .text`.
  - `trimsQueryAndIgnoresBlank`: `"  "` and `""` → `[]`; `" menu "` matches "Café Menu".
  - `includesHiddenAndLockedLayers`: a hidden text and a locked text both match.
  - `excerptsLongTextAroundTheHit`: content of 200 chars with "needle" at offset 150 → excerpt contains "needle", starts with "…", is at most 82 characters; newlines in content become spaces.
- [ ] **Step 2:** Run `swift test --package-path native --filter FudehandCoreTests.DesignFindTests` → fails (no `DesignFind`).
- [ ] **Step 3: Implement `DesignFind.matches`.** Trim the query with `.whitespacesAndNewlines`; empty → `[]`. Depth-first over `document.nodes` / `children`. Use `String.range(of:options: [.caseInsensitive, .diacriticInsensitive])` on `node.text?.content` first, then `node.name`. Excerpt: the matched field with newlines replaced by spaces; if ≤ 80 characters use it whole, otherwise take an 80-character window starting 30 characters before the hit (clamped to the string), prefixing "…" when it does not start at 0 and suffixing "…" when it does not reach the end.
- [ ] **Step 4:** Rerun the filter → passes.
- [ ] **Step 5:** Commit `feat(canvas): 按文字内容与图层名查找图层的匹配规则`.
