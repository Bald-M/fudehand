# 已确认的实现需求：界面图鉴

本文件记录用户确认的实现范围，作为本地需求符合性审查基线。

## 目标与技术

在 `/Users/zhangzihan/Code/ui-atlas` 创建独立的本地前端项目，用于学习优秀设计师的移动、网页和桌面界面。采用 Vue 3、TypeScript、Vite、原生 CSS；DOM 实现画布，iframe 运行案例，轻量 Node 脚本统一启动，不引入画布库、组件库或业务后端。

## 工作台与画布

- 左侧搜索和选择作品，显示作者、原作链接与源码位置，每个作品有独立画布。
- 支持拖动空白、空格键拖动、滚轮平移；Ctrl/Cmd 滚轮以鼠标位置缩放，范围 10%～200%。
- 工具栏提供缩放、100%、适应全部；画框可聚焦，从标题栏拖动位置，并可恢复默认布局。
- 默认浏览模式拦截案例操作；交互模式允许正常点击、输入和滚动，始终保留退出按钮。
- 内置案例通过极小 postMessage 桥支持 Esc 退出，画布精确校验消息来源与来源窗口；导入案例提供同样接入方法。
- 中性灰、系统字体、细边框与少量强调色，支持跟随系统、浅色和深色；主要面向电脑浏览器，窄屏可收起侧栏。

## 案例与配置

- 使用 pnpm 工作区，案例各自保留技术栈、入口、依赖与样式，支持 Vue、React 和纯 HTML。
- `catalog.json` 是配置权威来源，描述作品资料、启用状态、源码目录、启动参数数组、固定端口、预览基础 URL、画框 ID/路径/尺寸/默认位置。
- 标准 URL 规则解析画框路径；多个画框可共享一个案例进程。
- 默认手机、网页、桌面画框分别为 390×844、1440×900、1280×800，可修改。
- 内置原创 Vue 三端日常计划作品与极简 React 灵感收集器，使用本地模拟数据，有真实关键交互。

## 启动与保存

- 根目录 `pnpm install` 安装，`pnpm dev` 同时启动画布与所有启用案例；默认仅监听本机，端口为 4400、4401、4402。
- 检查合理配置与端口，通过 HTTP 2xx 确认就绪；端口占用、启动失败或 30 秒内未就绪时明确报错，不自动换端口。
- Ctrl+C、终止信号或子进程异常时清理本次启动的全部进程组，包括孙进程，不触碰其它服务。
- 浏览器只挂载当前作品的 iframe，所有启用案例的开发服务继续运行，可通过配置停用不常用案例。
- 画框位置、视角、最近作品和主题保存在 localStorage；按稳定 ID 和布局版本区分，验证有限数值，忽略损坏或过期数据，存储禁用也可使用。
- 配置不被浏览器数据替换。修改启动配置后重启开发命令；保存偏好不写回源码。

## 验证与交付边界

- Vitest 验证坐标换算、缩放中心、拖动、聚焦和布局恢复。
- 自动化验证统一启动、HTTP 就绪、端口冲突、启动失败与进程组清理。
- 浏览器检查两个作品、多画框交互、样式隔离、明暗主题、键盘操作和刷新恢复。
- 执行类型检查、测试、各项目构建，以及本地 规范与需求符合性代码审查。
- 文档说明添加案例、接入源码、配置画框、Esc 桥和启动故障排查。
- 三端都是浏览器界面，不模拟真实设备系统；案例通过源码和配置维护，不做设计编辑器或在线代码编辑器。
- 接入现成源码可做必要本地适配，不承诺任意源码零修改运行。仅本地交付，不创建远程仓库或部署。
