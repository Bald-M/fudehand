# 本地验证记录

验证日期：2026-11-06。环境：macOS、Node.js 22.22.2、pnpm 11.7.0。全部使用原创演示和本地模拟数据，未连接业务后端或执行部署。

## 自动检查

`pnpm check` 全部通过：

- 全工作区 TypeScript / Vue 类型检查。
- Vitest 4 个测试文件、20 个测试：画布几何 4 项、布局存储 3 项、启动器 9 项、Esc 桥 4 项。
- UI Atlas、Still 和 Form & Field 三个应用构建。
- 画布产物 JavaScript 89.71 kB / gzip 35.13 kB，CSS 16.57 kB / gzip 4.23 kB。

启动器测试使用真实临时 HTTP 服务和子/孙进程，覆盖端口占用、HTTP 503、探测取消、超时、异常退出、TERM 后强制清理；不会终止无关的占用程序。

## 浏览器验收

在本机 Chrome 完成以下实际交互，另以应用内浏览器查看初始画布：

- 1440 × 900 桌面、390 × 844 窄屏：外壳无横向溢出，窄屏作品抽屉可打开、搜索、选择并收起。
- 明暗主题切换；刷新后恢复主题。搜索无结果时展示空态。
- Vue 三端预览；任务完成从 1/4 变为 2/4；打开新建任务原生弹窗。
- 原生弹窗打开时 Esc 只关闭弹窗，继续处于交互模式；再次 Esc 返回画布。React 详情弹窗同样通过。
- React 收藏、已收藏筛选和详情面板可用；切换到 React 时仅挂载 1 个 iframe，回到 Still 时为 3 个。
- 网页画框标题栏拖动 80 × 30 CSS 像素，在 100% 缩放下位置从 (470, 0) 变为 (550, 30)；刷新后位置和视角保持。
- 标题栏方向键移动、双击聚焦、画框内容双击进入交互、滚轮平移、设备标签聚焦、恢复默认布局均通过。鼠标锚点缩放另由几何测试验证。
- 检查时浏览器控制台没有 error / warn。测试后恢复默认布局与系统主题，清除临时视口覆盖。

## 启动与停止

实际执行根命令 `pnpm dev`，画布和两个案例的 4400 / 4401 / 4402 服务均通过 HTTP 就绪检查。验收后发送 Ctrl+C，并重新绑定检查全部三个端口，确认均已释放。

首次使用已安装依赖，直接运行 `pnpm dev` 即可。本项目仅本地交付，没有配置远程仓库、CI 或部署目标，因此未运行远程 CI 或发布步骤。
